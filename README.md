# AGE: (Yet) Another Game Engine

## About
This is personal project made in order to learn and use SDL3 and Makefiles.
 
Here are a list of resources this is based off of:

* https://wiki.libsdl.org/SDL3/
* https://wiki.libsdl.org/SDL3_image/
* https://makefiletutorial.com/
* https://michaelmacha.wordpress.com/2024/12/13/sdl3-in-c/


## Requirements
* make
* g++
* git

Quick install script for `pacman` users:
 ```
 pacman -S make git gcc
 ```
 
If you are on Windows, I recommend installing these requirements under [MSYS2](https://www.msys2.org/), 
just because it's a more universal Linux based development environment and you'll
find better support for it in online communities.
